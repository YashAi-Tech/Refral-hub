## What is Refral Hub?

**Refral Hub** is a referral tracking and management system designed to help businesses manage their referral programs efficiently. Track referrals, monitor conversions, and manage your referral network all from a single dashboard.

> Looking for the AI-powered version? Check out [Refral Hub 2.0](https://github.com/YashAi-Tech/Refral-hub-2)!
